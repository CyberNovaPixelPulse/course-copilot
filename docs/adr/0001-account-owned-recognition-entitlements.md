# 以帳號紀錄管理辨識額度與匯出資格

設計決策已確認，對應本機實作已加入；正式環境尚未切換。帳號資料庫紀錄是所有來源辨識額度與匯出資格的最終依據，瀏覽器憑證不能自行恢復或轉移權益；此選擇取代部分權益只保存在簽章憑證的方式，以保證跨裝置一致及不同帳號隔離，代價是使用權益時需要依賴資料庫。辨識額度與匯出資格分開，額度用完不取消已取得的匯出資格；現有價格與方案保留，舊權益遷移方式另待決定。

舊權益採可驗證帳號歸屬才自動恢復的原則；證據不足時保存待核對，不直接轉給當前帳號或刪除。具體遷移證據與核對流程尚待設計。資料庫不可用時暫停新辨識、額度入帳及需要重新驗證資格的匯出，不退回以舊憑證授權；已載入課表仍可編輯，故障訊息不得誤報為額度不足或要求重新付款。

證據不足的舊權益由登入使用者在站內提出核對請求，保存待核對證據；管理者使用受控工具核對後補登，記錄理由並防止重複補登，本次不建立完整管理後台。正式切換前先盤點實際可用證據，不承諾無法還原的舊餘額；具體證據規則需依盤點結果完成。
