# 辨識前保留額度，成功後正式扣次

設計決策已確認，對應本機實作已加入；正式環境尚未切換。開始辨識前先保留一次額度，避免同一份額度被並行工作重複使用；產生至少一筆可用課程並保存必要紀錄後才正式扣次，失敗則釋放保留。此選擇由產品吸收失敗辨識的模型成本，並增加保留與恢復的處理複雜度，以保證不因失敗扣次且不超用剩餘額度；中斷恢復、保留期限與重試方式另待決定。

扣次以伺服器保存的工作結果為準，不以頁面是否仍開啟為準；成功結果需可由原帳號稍後取回。工作長時間未完成時保留須能過期釋放，釋放後遲到的舊工作不得再扣次或宣告成功。結果採短期保存，具體期限與恢復方式尚待決定。

保留期限初始採三分鐘；明確失敗立即釋放，成功與逾期釋放僅能有一方生效。成功課程結果自完成起保存七天，只供原帳號取回，不額外保存原始圖片，也不包含辨識後手動修改的跨裝置同步；課程內容到期刪除，必要的扣次及防重複紀錄另行保留。

同一次送出在斷線重試、重整或重複點擊時沿用同一工作識別：執行中查進度，成功取回結果，失敗或逾期後由使用者明確重新送出才建立新工作並保留額度。日後主動再次辨識相同圖片算新工作。

上傳區提供最近辨識入口，列出七天內的工作狀態與可取回的成功結果；由使用者主動恢復，背景結果不得覆蓋正在編輯的課表。失敗或逾期顯示未扣次，重新辨識由使用者選擇，不自動建立新工作。此功能不包含永久課表收藏或編輯同步。
