# 集中帳號權益生命週期

設計決策已確認，對應本機實作已加入；正式環境尚未切換。帳號額度 module 擁有授予、查詢、保留、扣除、釋放與匯出資格規則，並掌握辨識成功結果保存與正式扣次的一致性；呼叫端透過同一 interface 操作，不再自行協調對帳、計數與扣次順序。圖片辨識規則、付款真偽驗證與畫面呈現保留各自責任，資料庫 adapter 沿用 Turso 與記憶體 libSQL。

正式環境的扣次只能來自成功辨識工作，移除 /api/user/usage POST 直接增加用量的能力，保留用量查詢。測試與開發調整不得繞過正式環境的扣次規則。此選擇以集中一致性規則取得 locality 與 leverage，避免僅增加 shallow 轉呼叫 module；詳細 interface 與檔案配置待設計。
