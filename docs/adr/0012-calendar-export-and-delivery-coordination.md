# 集中行事曆輸出與交付協調

Q1–Q15 與完整共同理解已確認，設計討論完成。規格已發布為 [GitHub Issue #41](https://github.com/CyberNovaPixelPulse/course-copilot/issues/41)，標記 ready-for-agent。核准的七張子票 #42–#48 已發布，皆標記 ready-for-agent，並回讀驗證原生子 Issue 與阻擋關係；父規格本文及狀態不變。已依子票實作；本機驗收方式與真機限制見行事曆匯出驗收文件。

Q1：行事曆輸出與交付 module 擁有一次匯出的進度、結果、重試及交付協調，包含課表驗證、後端檔案準備、登入／資格／錯誤處理與交付。一般下載及 Apple 日曆各自提供交付 adapter。既有 ICS 產生器仍擁有檔案內容，共用課程時段 module 擁有有效性，後端帳號 module 決定匯出資格；分享圖片維持自己的繪製責任，但使用同次匯出資料。集中跨入口的協調，而非僅在既有產生器外增加轉呼叫。

Q2：每次匯出固定使用按下匯出當下的課表快照，ICS、分享圖片與後續交付皆對應同份內容。等待期間可編輯目前課表；輸出修改後內容須明確啟動新一次匯出。重試不得悄悄改用目前課表，舊結果不得覆寫目前課表，畫面應能辨認結果對應先前版本。

Q3：區分檔案已準備、已觸發下載／交付及使用者完成匯入。網站僅顯示可確認階段，例如檔案已準備、已觸發下載、已開啟交付入口並請使用者依裝置提示完成；無可靠回報時不宣稱檔案已保存或事件已加入日曆。交付未完成時保留本次已準備結果，供使用者明確重試或改用其他交付方式；後續生命週期與資格處理待下一輪確認。

Q4–Q6 已確認：同頁一次只協調一個匯出。準備期間顯示進度，重複點擊只呈現同一次狀態，不另送請求。課表修改後，可明確選擇改用目前課表重新匯出，舊操作立即失效，舊回應不得觸發下載或開啟結果視窗。

匯出結果只保留於目前頁面、目前帳號的記憶體；登出、切換帳號或離開頁面後失效，遲到回應不得下載或顯示。關閉結果視窗只收起視窗，同頁同帳號可重新開啟同次結果。重整後需重新匯出，不新增永久課表或匯出檔案保存。

尚未取得檔案時，使用者明確重試以同一份課表快照向後端重新準備，重新確認登入及匯出資格；已取得檔案後，同頁同帳號的重新下載或改用 Apple 日曆直接交付同一份 ICS，不重新產生。說明重複匯入可能產生重複事件，不保證日曆應用程式自動合併。

Q7–Q9 已確認：單次檔案準備最多等待三十秒，超時停止本次前端等待並保留快照供明確重試；舊回應不再交付，不自動重送，也不宣稱伺服器已取消。此限制不改辨識期限或付款流程。

區分課表無效／空白、需要登入／匯出資格、準備失敗及已知交付失敗。無效資料指出問題並回到目前課表修正，修正後明確開始新匯出。登入或資格問題沿用既有入口，完成後由使用者明確重試，不自動下載、恢復或覆寫課表。網路、逾時及準備失敗保留原快照供重試準備；已知交付失敗保留 ICS 供重試或切換方式，無法觀察的裝置結果提示自行確認，不誤報成功或失敗。帳號失效仍依 Q5 清除本次可操作狀態。

僅偵測為 iPhone／iPad 時呈現專用交付入口及指引，其他裝置提供一般 ICS 下載；裝置偵測只調整介面，不作成功證據。專用入口旁仍提供一般下載。移除模仿系統通知的示意列，說明後續操作依裝置提示完成，不保證出現特定系統畫面。

Q10–Q12 已確認：使用者明確啟動匯出，檔案準備完成後自動觸發一次一般下載並顯示結果視窗；僅仍有效的當次操作可觸發。重複點擊、重開視窗或重新渲染不再次下載。Apple 專用交付與後續重新下載皆需明確點擊，僅宣稱已觸發下載，不宣稱已保存。

ICS 準備完成即可交付，分享圖片獨立管理準備中、可用及失敗，使用同次快照。圖片失敗顯示原因與重試產生圖片，不重新請求 ICS，也不阻擋行事曆下載；圖片未成功前不可下載，不沿用上一張圖片。

本輪維持既有 ICS 內容政策：預設每週重複十六次；以產生時的伺服器日期往後找對應星期，當天即使上課時間已過仍使用當天；事件時間不附明確時區標記，事件識別包含課名、星期、開始時間及課程／時段順序。保留既有時段有效性與完整輸出規則，不新增學期日期、時區設定、穩定事件識別或重複匯入去重。測試確認交付重構不改事件內容，畫面說明日期與十六次規則，不稱為依學校學期安排。

Q13–Q15 已確認：準備階段檢查成功狀態、行事曆內容類型、非空內容及基本完整標記，符合才標示檔案已準備。空內容、HTML 或不完整回應視為準備失敗，保留快照供明確重試，不觸發下載或開啟成功結果。不另建瀏覽器 ICS 解析器，事件內容正確性仍由既有產生器及測試負責。

Apple 專用交付已知無法執行時顯示原因，保留同份 ICS 供使用者明確選擇一般下載。若只能確認觸發交付，請使用者查看裝置提示並保留下載選項；不自動切換方式、不靜默無反應、不自動重複交付。正式網頁準備統一使用既有登入保護的 JSON POST，既有 GET／表單相容入口本輪保留，不新增公開下載連結或雲端檔案保存。

主要測試邊界為匯出協調介面，使用可控制的 HTTP、時間與交付 adapter 驗證快照一致、重複點擊、替換匯出、三十秒上限、明確重試、帳號失效及遲到回應。瀏覽器驗證首次下載只觸發一次、重開視窗不重下載、ICS 與分享圖同份快照、圖片失敗不阻擋行事曆、非 iOS 不顯示無效 Apple 按鈕及交付失敗替代入口。沿用登入、匯出資格、時段有效性、事件內容與付款恢復回歸。

工程驗收與真實裝置匯入分開：另行驗證 iPhone／iPad 及實際日曆結果；模擬裝置與 adapter 通過只證明工程流程。真機驗證未完成時，明確標示 Apple 專用交付尚未完成真機驗收，不宣稱已成功匯入。工程驗收不執行真實模型、付款或部署。
