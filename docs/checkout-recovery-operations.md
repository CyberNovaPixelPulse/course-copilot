# 付款返回與課表恢復驗收

## 可重現檢查

- `npm run test:checkout`：透過 module 對外操作驗證，控制付款、儲存及時間；涵蓋兩種付款方式、保存失敗／略過、建立失敗、多次備份、七天期限、帳號隔離、取消返回、查詢重疊、返回重播、逾時、遲到回應與損壞資料。
- `npx playwright install chromium`：安裝瀏覽器，首次執行需要。
- 一個終端執行 `npm run dev -- --hostname 127.0.0.1`，另一個執行 `npm run test:checkout:browser`。可用 `CHECKOUT_TEST_ORIGIN` 指向另一個本機埠。
- `npx tsc --noEmit`、`npm test`、`npm run build`，以及相關修改的 ESLint。

瀏覽器腳本攔截所有應用 API，使用合成登入、課表與付款，不向實際付款、模型或帳號 API 發送請求。驗證雙金流離站返回不自動載入、明確恢復及覆寫確認、新分頁持久保存、登入接續及錯誤帳號、取消返回、約三十秒尚待確認及重查、損壞隔離、到期、保存失敗確認略過及建立付款失敗，以及略過本機保存後取消返回、遲到舊權益快照與辨識回應。未處理的 API 直接回傳測試錯誤，不放行實際 API。

## 實際金流另行驗收

以下需另行授權，這次不執行：

1. 以核准帳號及交易額度分別完成 ECPay 與 Stripe 真實付款，核對後端一次入帳及返回提示。
2. 驗證供應商實際取消／返回行為，包含 Stripe 取消返回的付款嘗試線索及 ECPay 付款識別標頭。
3. 驗證付款成功但未返回後的既有履約與帳號權益；本機 UI 替身不證明正式金流或資料庫設定。

## 保存限制

備份只在原瀏覽器、原網站來源及原帳號可由畫面讀取，固定七天。清除網站資料、改用無痕模式、換裝置或換來源後不能承諾恢復。跨裝置只能另取既有近期辨識結果，不含付款前的手動修改。到期備份停止提供恢復；不以付款成功或恢復操作延長保存。
