# 可編輯課程時段

來源：GitHub #32，子票 #33–#40，ADR 0011。

`lib/course-time.ts` 集中課程時段的解析、正規化、有效性、顯示範圍、重疊關係、移動與端點調整。新增、週曆、付款草稿、辨識批次及輸出皆經此介面處理時間；辨識器仍擁有圖片節次轉換與嚴格內容檢查，不改動其時間表或支援格式。

- `isCourseStructure` 只確認可安全讀取與保存的欄位結構，刻意允許無效星期、無效時間字串及沒有時段的課程。它不代表可以輸出。
- `inspectSchedule` 回傳保留問題原值的課程、可定位的問題清單、有效時段推導的時間視窗及星期欄。有效時間統一 HH:mm；沒有時段的課程亦為待修正內容。
- `exportableCourses` 要求非空且所有時段有效，失敗交付具體問題；ICS、分享圖與下載畫面共用，不輸出部分資料。
- `changeSlotTime` 以原始時段與累積位移計算預覽，不以最近一次預覽累加。整段移動保留分鐘及時長；端點調整只改一端。可見範圍由一次拖曳開始時固定，放開後重算。
- `overlappingSlots` 與 `placeTimeRanges` 分別提供重疊關係及同日並排欄位；使用嚴格重疊判斷，首尾相接不衝堂。週曆與分享圖使用同一排列，避免連鎖重疊越過星期欄。

週曆另提供課程明細入口，極短時段也可透過文字與鍵盤精確編輯；無效資料由待修正清單進入。時間與星期先暫存在編輯視窗，確認且驗證成功後套用，取消不變更；課名、教師及地點沿用既有即時修改範圍。最後時段刪除須確認移除整門課。

付款草稿以結構安全作保存條件，恢復時整理可明確解讀的時間，問題資料仍保留供修復；帳號隔離與原建立起七天期限不變。辨識批次仍要求完整有效的成功課程，並沿用原本去重與扣次責任；本輪僅移除重複時間驗證及重疊判斷。

分享圖包含全部時段的編號明細，短小或擁擠區塊可對照課名、星期及起訖時間。長課名按實際文字高度換行，畫布隨明細增加高度；時間條保留實際時長，不用加長課程換取可讀性。
