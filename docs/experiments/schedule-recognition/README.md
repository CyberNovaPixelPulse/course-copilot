素材僅納入使用者確認的目前支援格式：時間欄右側五個等寬平日欄及既有兩套節次表。每張圖片先標註素材識別、課名、星期、節次、教室、預期合併後時段及預期拒絕原因，再進行辨識，避免依模型輸出反改答案。
