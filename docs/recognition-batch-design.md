# 瀏覽器辨識批次協調

規格 GitHub #24，實作票 #25–#31；詞彙與決策依 ADR 0010。

`createRecognitionBatch` 是呼叫端及測試共用的 seam。準備完成、送出／繼續、重試、原工作查詢、略過、結束及候選載入都經同一 interface。送出、查詢、時間、工作識別、圖片指紋、本機儲存與帳號權益操作為 adapter 依賴；裁切及壓縮保持原有職責。

批次逐張執行，遇失敗或未知便暫停。成功結果只更新候選，不改目前課表；載入時另取完整候選並確認覆寫。合併只移除完全相同的課名、教師、星期、時間及教室，不猜班級、不跨圖合併連續節次；重疊另行提醒。

同頁僅一個可操作批次，新選圖及拖放皆透過同一判斷。結束使該批後續協調失效，但不取消後端；遲到有效權益結果仍交給原帳號的共用 module。帳號切換則停止等待並清除舊批可操作資料，舊權益 module 負責拒絕舊登入階段結果。

裁切準備失敗停留當張，顯示重試／略過／取消；其他已準備圖片仍保留。準備完成後送出只涵蓋目前批次，不引用累積預覽清單。預覽 URL 在新批次、結束或離開時清理。圖片指紋讀取故障也可由批次明確重試，不繞過既有待確認線索；立即重新連接會清除舊鎖，舊請求清理不能干擾新批次。

工作線索依帳號與實際送出圖片的 SHA-256 定位，版本化記錄包含工作識別、指紋及建立時間，七天到期、查詢不延長。可辨識的舊工作識別先查原工作；過期或損壞須經新工作扣次警告確認。未能保存時不 POST，同頁可用原本尚未送出的識別重試保存。成功、明確失敗或逾期結束待確認用途；清理前比對儲存中的工作識別，舊頁面遲到結果不得刪除較新工作線索。原工作查詢回覆未登入只使權益登入階段失效，工作仍待確認並保留線索，不宣告工作失敗。

送出最多等待九十秒，查詢十五秒。送出網路／回應故障自動查原工作一次，未知、查不到或查詢故障均暫停，不自動重送。準備及查詢不會建立新後端工作；成功扣次、三分鐘保留及七天原始結果政策維持原位。
