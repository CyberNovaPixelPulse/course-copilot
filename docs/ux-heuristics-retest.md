# UX Heuristics 重驗（2026-10-27）

實作：edc3d08；審查基準 bb65366。原稽核 5/10，本輪重驗 9/10。這是本機已查核流程的啟發式評分，不是正式環境、真人可用性或完整 WCAG 認證。

## 已修正的八項

1. 整份編輯草稿一起提交；取消不寫回課名、教師、教室、星期或時間。
2. 編輯草稿保存於此瀏覽器七天，按帳號隔離，明確選擇恢復；未解決舊草稿前不自動覆蓋。保存失敗有提示、離開警示及可重試的保存操作。
3. 範例替換可復原；顯示範例期間保留原草稿，避免重整後只剩範例。
4. ICS 準備後先顯示檔案的起訖日期與浮動本地時間、每週十六次政策；下載由使用者明確觸發。FAQ 已修正，未改動日期產生規則。
5. 新增、編輯、裁切、付費與匯出使用共用原生 dialog，管理焦點、Escape、背景 inert 與關閉返回焦點。
6. 手機提供星期快速定位與橫向滑動說明，保留精確清單替代。
7. 繁中明細使用在地化星期。
8. 觸控裝置常用按鈕至少 44px；精確時間格的課程卡保留實際時長，另提供足尺寸清單操作。

## 評分依據與殘餘問題

Quick Diagnostic 從 10 分起算：網站／頁面、主要動作、單頁導覽、已查核狀態與錯誤回饋、鍵盤／觸控及互動名稱均可用；搜尋與這個工具的主要任務無關，不扣分。原日期與星期語意問題已修正。

「取消／復原」列仍有一項 S2 次要問題，扣 1 分，故重驗為 9/10：多時段課程刪除其中一段時，不會出現確認，也沒有立即復原入口。另以合成雙時段課程，經既有付款前課表恢復介面載入並操作，確認第一段被刪、另一段保留、確認對話框 0、復原操作 0。程式證據：app/components/WeeklyCalendar.tsx 的 deleteSlot；細節紀錄 /tmp/ux-retest-residual.json。

要到 10/10，應補足此刪除操作的復原：保留被刪時段，提供明確的復原入口，並避免復原覆蓋刪除後的新編輯，再重走刪除／復原與鍵盤流程。這是重驗新發現的殘餘項目，原先八項皆已修正；本輪未新增 GitHub 票。
